# The One-Line Laugh

One funny line in a single sentence. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 200 characters, exactly one sentence ending in a single period — then reads the file back and verifies the bytes match.

> "My smartwatch congratulated me on burning 400 calories, then reminded me I ate them back in a single meeting biscuit."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-laugh-out node main.ts
```
